# Aya Kids - متجر الأطفال المتقدم

## نظرة عامة
Aya Kids هو متجر إلكتروني متكامل لمنتجات الأطفال مع لوحة تحكم إدارية متقدمة تعمل بالكامل من قاعدة البيانات بدون أي بيانات ثابتة.

## المميزات الرئيسية

### المتجر الرئيسي
- ✅ تصميم متجاوب مع أنيميشنات متقدمة
- ✅ نظام عربة تسوق متكامل مع تأثيرات بصرية
- ✅ بحث متقدم مع تصفية المنتجات
- ✅ تصنيفات المنتجات والفلاتر
- ✅ عداد زوار تلقائي
- ✅ نظام تقييمات ومراجعات
- ✅ دعم اللغة العربية والإنجليزية

### لوحة التحكم الإدارية
- ✅ إحصائيات تلقائية وتحديثات مباشرة
- ✅ إدارة المنتجات (إضافة، تعديل، حذف)
- ✅ إدارة الفئات
- ✅ إدارة الطلبات والعملاء
- ✅ تحليلات المبيعات مع رسوم بيانية
- ✅ عدد الزوار اليومي التلقائي
- ✅ نظام إشعارات ذكي
- ✅ تصدير البيانات

## المسارات والوظائف

### المتجر الرئيسي
- `/` - الصفحة الرئيسية للمتجر
- `/dashboard.html` - لوحة التحكم الإدارية

### واجهة برمجة التطبيقات (API)
- `GET /tables/products` - جلب جميع المنتجات
- `GET /tables/products/{id}` - جلب منتج محدد
- `POST /tables/products` - إضافة منتج جديد
- `PUT /tables/products/{id}` - تحديث منتج
- `DELETE /tables/products/{id}` - حذف منتج
- `GET /tables/categories` - جلب جميع الفئات
- `GET /tables/orders` - جلب الطلبات
- `GET /tables/customers` - جلب العملاء
- `GET /tables/visitors` - جلب بيانات الزوار

## قواعد البيانات

### جدول المنتجات (products)
- `id` - معرف فريد
- `name` - اسم المنتج بالعربية
- `name_en` - اسم المنتج بالإنجليزية
- `description` - وصف المنتج بالعربية
- `description_en` - وصف المنتج بالإنجليزية
- `price` - السعر
- `discount_percentage` - نسبة الخصم
- `images` - مصفوفة روابط الصور
- `category_id` - معرف الفئة
- `stock_quantity` - كمية المخزون
- `status` - الحالة (active/inactive/draft)
- `is_featured` - هل المنتج مميز؟

### جدول الفئات (categories)
- `id` - معرف فريد
- `name` - اسم الفئة بالعربية
- `name_en` - اسم الفئة بالإنجليزية
- `description` - وصف الفئة
- `image` - رابط صورة الفئة
- `is_active` - هل الفئة مفعلة؟
- `sort_order` - ترتيب العرض

### جدول الطلبات (orders)
- `id` - معرف فريد
- `customer_name` - اسم العميل
- `customer_email` - بريد العميل
- `customer_phone` - هاتف العميل
- `items` - مصفوفة المنتجات المطلوبة
- `total` - المجموع الكلي
- `status` - حالة الطلب
- `payment_status` - حالة الدفع

### جدول الزوار (visitors)
- `id` - معرف فريد
- `ip_address` - عنوان IP
- `visit_date` - تاريخ الزيارة
- `page` - الصفحة التي تمت زيارتها
- `device_type` - نوع الجهاز (desktop/mobile/tablet)
- `country` - الدولة

## الإحصائيات التلقائية

### لوحة القيادة
- **إجمالي الطلبات**: يتم حسابه تلقائياً من جدول الطلبات
- **إجمالي الإيرادات**: يتم حسابه من الطلبات المكتملة
- **عدد العملاء**: يتم حسابه من جدول العملاء
- **عدد المنتجات**: يتم حسابه من جدول المنتجات
- **عدد الزوار اليومي**: يتم حسابه من جدول الزوار
- **معدل النمو**: يتم حسابه مقارنة بالفترة السابقة

### الرسوم البيانية
- **مبيعات شهرية**: تُحدث تلقائياً من بيانات الطلبات
- **المنتجات الأكثر مبيعاً**: تُحسب من عدد مرات طلب كل منتج
- **تحليلات الزوار**: تُحدث من بيانات جدول الزوار

## كيفية الاستخدام

### إضافة منتج جديد
1. انتقل إلى لوحة التحكم
2. اضغط على "إدارة المنتجات"
3. اضغط على زر "إضافة منتج جديد"
4. املأ النموذج بالمعلومات المطلوبة
5. اضغط "حفظ"

### إدارة الفئات
1. من لوحة التحكم، اختر "الفئات"
2. استخدم زر "إضافة فئة جديدة"
3. املأ معلومات الفئة
4. اضغط "حفظ"

### مشاهدة الإحصائيات
- تظهر الإحصائيات في لوحة القيادة بشكل تلقائي
- يتم تحديث الرسوم البيانية بشكل دوري
- يمكنك تصفية البيانات حسب التواريخ

## التقنيات المستخدمة

### الواجهة الأمامية
- HTML5، CSS3، JavaScript ES6+
- CSS Grid و Flexbox للتصميم المتجاوب
- CSS Animations و Keyframes للأنيميشن

### مكتبات الجافاسكريبت

### قاعدة البيانات

- جداول متعددة للمنتجات، الفئات، الطلبات، العملاء، والزوار
